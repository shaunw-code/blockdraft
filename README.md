# BlockDraft
BlockDraft is a browser design tool where users can quickly design streets, campuses, public spaces and neighborhoods.

## Features

- Place & design buildings
- Draw & customize roads
- Create and design parks and trees
- Create sidewalks and green space
- Build school campuses
- Build & design houses.
